# 完整售前周期

串联售前 5 个关键步骤，适用于新商机的全流程跟进。

## 步骤说明

1. **线索评估** (`lead-score`) — 评估商机质量，决定是否值得投入
2. **行业简报** (`briefing`) — 了解客户行业背景和痛点
3. **战略分析** (`strategy`) — 用 KPMG 框架诊断客户战略痛点
4. **方案设计** (`solution`) — 输出 8 步标准化方案
5. **战局推演** (`simulate`) — 推演方案风险和路径选择

## 使用方式

```bash
sa cycle
```

每个步骤执行完后，会基于前一步的结果继续下一步。
适合新接到的重要商机，需要全面准备的情况。
